# Risk: Simulation Inconsistency

## Description

The simulation outputs (e.g., completion times, resource usage) become inconsistent with the "ideal" schedule generated by the algorithm. This makes dashboards unreliable and undermines user trust in the system.

## Likelihood

Medium

## Impact

High

## Mitigation Plan

- Use a single, shared data source for the schedule and simulation states to prevent divergence
- Create a robust mapping system that translates schedule events directly into simulation events
- Write unit tests to verify that for simple scenarios, the simulation mirrors the schedule exactly
- Implement periodic consistency checks between schedule and simulation states

## Contingency Plan

- Pause the simulation and force a re-synchronization with the schedule
- Provide a "discrepancy alert" on the dashboard that informs the user that the current simulation state is out-of-sync
- Allow manual override to correct simulation state to match schedule

## Status

Open
